# The Bad List

A custom Extreme Demon ranking website built with HTML, CSS, and JavaScript.

## Features

- 🔎 Search demons by:
  - Level name
  - Creator
  - Verifier

- 🏆 Displays:
  - Rank
  - Level name
  - Creator
  - Verifier
  - Difficulty
  - Thumbnail

- 📱 Responsive design for mobile and desktop
